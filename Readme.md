# LexiMind - Dyslexic Handwriting Correction System

## 📌 Project Description
LexiMind is a Machine Learning based system that detects and corrects dyslexic handwriting using OCR and NLP techniques.

## 🚀 Features
- Upload handwritten image
- Extract text using OCR (Tesseract)
- Correct dyslexic spelling errors
- Display corrected sentence

## 🛠 Technologies Used
- Python
- OpenCV
- Tesseract OCR
- NLP
- Machine Learning

## ⚙ Installation
pip install -r requirements.txt

## ▶ Run Project
python app.py
